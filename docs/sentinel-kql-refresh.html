Microsoft Sentinel KQL (quick refresh)

This repo ships three optional Sentinel queries under kql/. They read AuditLogs and look for abuse patterns aligned with the Sigma rules in rules/.

What each query does

FileIdea
intune_mass_wipe_retire_burst.kqlMany wipe, retire, delete, or lock operations from one actor inside a one hour bin.
intune_policy_change_velocity.kqlHigh rate of device or compliance policy changes per actor per hour.
entra_privileged_intune_window.kqlRole management events (user added to a role) followed within four hours by Intune device category actions from the same user.

How to run

  1. Open Microsoft Sentinel, Logs.
  2. Paste a query, run over a short lookback first.
  3. Tune thresholds at the top of each file (min_ops, min_changes, gap).

Tenant caveat

OperationName and ActivityDisplayName strings vary by product version. Export a few real rows from AuditLogs where Category == "Device" and adjust the has_any lists to match your environment.
